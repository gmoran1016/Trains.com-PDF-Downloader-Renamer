Trains.com Archive 2.0.2 improves long magazine archive scans and recovery when Trains.com temporarily denies access.

- Lighter archive requests reduce the images, scripts, and embedded frames loaded while finding issues.
- Temporary 403 and rate-limit blocks receive longer, cancellable retry waits that respect the site's retry instructions.
- Chrome checks failed or empty archive responses before the scan ends, helping prevent missed issues.
- Authentication requests use the active browser's refreshed cookies when available, with saved cookies as a backup.
- Stop works during archive pacing and retry waits. Missing-issue jobs correctly report cancellation even when no requested issue has been found yet.
- Issues discovered before an incomplete scan remain available for processing, and blocked scans continue to report a failure.

Windows portable users should close the app, replace the executable in its existing folder, and keep adjacent data files to retain settings and saved login information.
