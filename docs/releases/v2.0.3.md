Trains.com Archive 2.0.3 fixes magazine issues being skipped because of stale download history.

- Before skipping an issue, the downloader checks that its PDF is actually in the selected destination. A saved completion with no matching file is cleared and the issue is retried.
- Read-only issues with no available PDF are no longer recorded as completed, so later runs can retry them when access changes.
- Missing-issue jobs and the special-issue cache also recheck the destination before treating an issue as downloaded.

Windows portable users should close the app, replace the executable in its existing folder, and keep adjacent data files to retain settings and saved login information.
